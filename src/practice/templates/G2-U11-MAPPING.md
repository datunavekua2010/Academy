# Grade 2 Unit 11: გაზომვა და გეომეტრია (Measurement & Geometry)

## Overview
Unit 11 (`g2-gazomva-geometria`) introduces Grade 2 students to standard units of measurement (meters, centimeters, kilograms, grams, temperature in °C) and geometric foundations (flat vs. solid shapes, perimeter, side counting, angle counting, grouping by sides, inside/outside topological relationships, congruent/equal shapes, and reflectional symmetry).

## Architecture & Subtopics
The unit contains **78 dynamic question templates** (Q01–Q78) evenly distributed across **13 subtopics** (6 questions each) covering progressive difficulty levels (Level 1, Level 2, Level 3):

1. **U11.1: მეტრი და სანტიმეტრი** (`u11-meters-and-centimeters`, Q01–Q06)
   - Q01 (Level 1, Numeric): რამდენი სანტიმეტრია 1 მეტრში (1 მ = 100 სმ).
   - Q02 (Level 1, Numeric): რამდენიმე მეტრის გადაყვანა სანტიმეტრებში (m × 100).
   - Q03 (Level 2, Numeric): მეტრისა და სანტიმეტრის გადაყვანა სანტიმეტრებში (m × 100 + cm).
   - Q04 (Level 2, MC): სანტიმეტრების დაშლა მეტრებად და სანტიმეტრებად.
   - Q05 (Level 3, Numeric): 1 მეტრამდე აკლებული სანტიმეტრების პოვნა (100 − len).
   - Q06 (Level 3, MC): უდიდესი სიგრძის არჩევა მოცემული სიგრძეებიდან.

2. **U11.2: სიგრძის საზომი ერთეულები** (`u11-units-of-length`, Q07–Q12)
   - Q07 (Level 1, MC): მცირე საგნისთვის შესაფერისი ერთეულის არჩევა (სანტიმეტრი).
   - Q08 (Level 1, MC): დიდი ობიექტისთვის/სივრცისთვის შესაფერისი ერთეულის არჩევა (მეტრი).
   - Q09 (Level 2, Numeric): საგნის მეტრების გადაყვანა სანტიმეტრებში.
   - Q10 (Level 2, Numeric): სიგრძეების შედარება და სხვაობის გამოთვლა (lenA − lenB).
   - Q11 (Level 3, Numeric): ორი ლენტის საერთო სიგრძის გამოთვლა (a + b).
   - Q12 (Level 3, Numeric): შენობის/კარის სიმაღლის გადაყვანა მეტრიდან სანტიმეტრში.

3. **U11.3: წონის საზომი ერთეულები** (`u11-units-of-weight`, Q13–Q18)
   - Q13 (Level 1, MC): მსუბუქი საგნის წონის საზომი ერთეულის არჩევა (გრამი).
   - Q14 (Level 1, Numeric): რამდენი გრამია 1 კილოგრამში (1 კგ = 1000 გ).
   - Q15 (Level 2, Numeric): რამდენიმე ერთნაირი ნივთის საერთო წონა (count × w).
   - Q16 (Level 2, Numeric): წონების შედარება კილოგრამებში (wA − wB).
   - Q17 (Level 3, Numeric): გრამების შეკრება (wA + wB).
   - Q18 (Level 3, MC): მოცემული წონებიდან ყველაზე მძიმეს პოვნა.

4. **U11.4: თერმომეტრი და ტემპერატურა** (`u11-thermometer`, Q19–Q24)
   - Q19 (Level 1, Numeric): ტემპერატურის მომატების გამოთვლა (°C-ში).
   - Q20 (Level 1, Numeric): ნულზე დაბალი ტემპერატურის გააზრება (−T°C).
   - Q21 (Level 2, Numeric): ტემპერატურის დაკლების გამოთვლა.
   - Q22 (Level 2, MC): ყველაზე მაღალი ტემპერატურის არჩევა.
   - Q23 (Level 3, Numeric): ტემპერატურის დაცემის შემდეგ მიღებული მაჩვენებელი (t − drop).
   - Q24 (Level 3, Numeric): უარყოფითიდან დადებითამდე ტემპერატურის ზრდა (below + above).

5. **U11.5: ბრტყელი და სივრცული ფიგურები** (`u11-flat-and-solid-shapes`, Q25–Q30)
   - Q25 (Level 1, Numeric): სამკუთხედის გვერდების რაოდენობა (3).
   - Q26 (Level 1, MC): სივრცითი (მოცულობითი) ფიგურის ამოცნობა (კუბი/სფერო/ცილინდრი/პირამიდა).
   - Q27 (Level 2, Numeric): კუბის წახნაგების რაოდენობა (6).
   - Q28 (Level 2, Numeric): ოთხკუთხედის (კვადრატი, მართკუთხედი, რომბი, ტრაპეცია) გვერდები (4).
   - Q29 (Level 3, MC): რეალური საგნის ფორმის დაკავშირება გეომეტრიულ ფიგურასთან.
   - Q30 (Level 3, Numeric): კუბის წვეროების რაოდენობა (8).

6. **U11.6: პერიმეტრი** (`u11-perimeter`, Q31–Q36)
   - Q31 (Level 1, Numeric): კვადრატის პერიმეტრის გამოთვლა (4 × a).
   - Q32 (Level 1, Numeric): მართკუთხედის პერიმეტრის გამოთვლა (2 × (a + b)).
   - Q33 (Level 2, Numeric): სამკუთხედის პერიმეტრის გამოთვლა (a + b + c).
   - Q34 (Level 2, Numeric): კვადრატის გვერდის პოვნა პერიმეტრის მიხედვით (P : 4).
   - Q35 (Level 3, Numeric): მართკუთხედის პერიმეტრი გაზრდილი ზომებით.
   - Q36 (Level 3, Numeric): თვითნებური ოთხკუთხედის პერიმეტრი (a + b + c + d).

7. **U11.7: გვერდების დათვლა** (`u11-counting-sides`, Q37–Q42)
   - Q37 (Level 1, Numeric): ხუთკუთხედის გვერდების რაოდენობა (5).
   - Q38 (Level 1, Numeric): ექვსკუთხედის გვერდების რაოდენობა (6).
   - Q39 (Level 2, MC): ოთხკუთხედის ამოცნობა ჩამოთვლილ ფიგურებს შორის.
   - Q40 (Level 2, Numeric): მრავალკუთხედისა და სამკუთხედის გვერდების რაოდენობათა სხვაობა.
   - Q41 (Level 3, Numeric): რვაკუთხედის / მრავალკუთხედის გვერდების დათვლა.
   - Q42 (Level 3, MC): უდიდესი გვერდების რაოდენობის მქონე ფიგურის პოვნა.

8. **U11.8: კუთხეების დათვლა** (`u11-counting-angles`, Q43–Q48)
   - Q43 (Level 1, Numeric): სამკუთხედის კუთხეების რაოდენობა (3).
   - Q44 (Level 1, Numeric): კვადრატის / მართკუთხედის კუთხეების რაოდენობა (4).
   - Q45 (Level 2, Numeric): ხუთკუთხედის კუთხეების რაოდენობა (5).
   - Q46 (Level 2, Numeric): მრავალკუთხედისა და მართკუთხედის კუთხეების სხვაობა.
   - Q47 (Level 3, MC): მოცემული k კუთხის მქონე ფიგურის ამოცნობა.
   - Q48 (Level 3, Numeric): მრავალკუთხედში გვერდებისა და კუთხეების ტოლობის გააზრება.

9. **U11.9: ფიგურების დაჯგუფება გვერდების მიხედვით** (`u11-grouping-by-sides`, Q49–Q54)
   - Q49 (Level 1, MC): 3-გვერდიან ფიგურათა ჯგუფში შესაბამისი ფიგურის (სამკუთხედი) ჩასმა.
   - Q50 (Level 1, MC): ოთხკუთხედების ჯგუფის წევრის არჩევა.
   - Q51 (Level 2, MC): k-გვერდიანი ფიგურის შესაბამის ჯგუფში განაწილება.
   - Q52 (Level 2, MC): კონკრეტული ჯგუფის წევრის გვერდების რაოდენობა.
   - Q53 (Level 3, MC): რომელი ფიგურა არ ეკუთვნის მითითებულ ჯგუფს (odd-one-out).
   - Q54 (Level 3, Numeric): ორ ჯგუფს შორის ფიგურათა რაოდენობის შედარება.

10. **U11.10: შიგნით და გარეთ** (`u11-inside-and-outside`, Q55–Q60)
    - Q55 (Level 1, Numeric): ფიგურის შიგნით და გარეთ არსებული ელემენტების ჯამი (a + b).
    - Q56 (Level 1, Numeric): გარედან დამატებული ელემენტების რაოდენობის გარკვევა.
    - Q57 (Level 2, Numeric): ფიგურის შიგნით მოთავსებული ელემენტების დათვლა.
    - Q58 (Level 2, Numeric): შიგნით და გარეთ არსებული ელემენტების სხვაობის პოვნა (a − b).
    - Q59 (Level 3, Numeric): გარედან შიგნით გადატანის შემდეგ დარჩენილი რაოდენობა.
    - Q60 (Level 3, Numeric): შიდა და გარე ელემენტების გაერთიანებული დათვლა.

11. **U11.11: ტოლი ფიგურები** (`u11-equal-shapes`, Q61–Q66)
    - Q61 (Level 1, MC, optionCount: 2): ორი ტოლი კვადრატის ზომების შედარება (დიახ).
    - Q62 (Level 1, MC, optionCount: 2): ორი ტოლი მართკუთხედის ზომების შედარება (დიახ).
    - Q63 (Level 2, MC, optionCount: 2): ორი არატოლი კვადრატის შედარება (არა).
    - Q64 (Level 2, MC, optionCount: 2): მობრუნებული მართკუთხედების ტოლობის გააზრება (დიახ).
    - Q65 (Level 3, MC, optionCount: 2): სამივე გვერდით ტოლი სამკუთხედების შედარება (დიახ).
    - Q66 (Level 3, MC, optionCount: 2): სხვადასხვა გვერდის მქონე კვადრატების შედარება (არა).

12. **U11.12: სიმეტრია** (`u11-symmetry`, Q67–Q72)
    - Q67 (Level 1, Numeric): კვადრატის სიმეტრიის ღერძების რაოდენობა (4).
    - Q68 (Level 1, Numeric): არაკვადრატული მართკუთხედის სიმეტრიის ღერძების რაოდენობა (2).
    - Q69 (Level 2, MC): ვერტიკალური ღერძის მიმართ სიმეტრიული ლათინური დიდი ასო (A, M, T, V, W, Y).
    - Q70 (Level 2, MC): წრის სიმეტრიის ღერძების რაოდენობა (უსასრულოდ ბევრი).
    - Q71 (Level 3, MC, optionCount: 2): სარკისებური ერთნაირობის დაკავშირება სიმეტრიის ღერძთან (დიახ).
    - Q72 (Level 3, MC): ცენტრზე გამავალი ვერტიკალური და ჰორიზონტალური ხაზების მიმართ სიმეტრიული ფიგურის ამოცნობა.

13. **U11.13: შერეული გამეორება** (`u11-mixed-review`, Q73–Q78)
    - Q73 (Level 1, Numeric): მეტრისა და სანტიმეტრის გადაყვანა სანტიმეტრებში.
    - Q74 (Level 1, Numeric): კვადრატის პერიმეტრის გამოთვლა.
    - Q75 (Level 2, MC): სივრცითი ფიგურის ამოცნობა.
    - Q76 (Level 2, Numeric): ტემპერატურის ცვლილების გამოთვლა.
    - Q77 (Level 3, Numeric): გვერდების დამატება სასურველ მრავალკუთხედამდე.
    - Q78 (Level 3, MC): სანტიმეტრების გადაყვანა მეტრსა და სანტიმეტრში.
