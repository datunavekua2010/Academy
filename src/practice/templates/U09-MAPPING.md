# U09 — შერეული ამოცანები (mixed problems)

Grade 1, `topicId: 'Sereuli-amocanebi'`. 49 templates over 8 subtopics, three
levels each. Every number, noun, name and option is generated; every answer is
computed from what the student is shown.

The unit's job is not a new operation — U06 and U07 taught those. It is the
*choice*: which operation does this story need, do both sides of this equality
really match, and does a two-step sentence have to be read in order.

## Recasts, and why

The engine grades **one answer per question**. Four reference items could not be
answered in one place, so each was recast without changing the reasoning it
tests. All four are marked in the source.

1. **Q48 `__ + 4 = 15 − __` — two blanks, one answer.** The two blanks do not
   hold the same number (one is the right side less four, the other is free), so
   a single markable answer cannot cover both. Recast as `__ + 4 = 15 − 6`: the
   student makes the sides meet, which is exactly the Q48 skill, with the second
   value printed instead of asked for. `g1-u09-8-both-sides` asserts that the
   answer differs from every printed number, so nothing gives the blank away.

2. **Q7/Q8 „which operation?“ — a coin flip unless the operation is drawn
   first.** The operation is drawn (`'add' | 'subtract'`), and the sentence is
   built to match that draw, so both answers really occur. Verified: 191
   subtraction, 209 addition over 400 draws.

3. **Q35 „choose the expression with sum 16“ — exactly one right option.** The
   correct expression is *built* to the target (`a = target − b`), and every
   distractor is a one-number miss. The test re-adds every option and asserts
   exactly one reaches the target.

4. **Q31/Q34 ask for a pair of numbers** („4 and 5“, „19; 8“). Graded as one
   compound answer in the order the sentence names them — „2, 7“ — the same
   device U07 uses for „name all three terms“. Both wrong options are order
   errors, so the pair itself is never wrong, only the reading of it.

Q49 and Q50 (the mixed-review pair) are folded into U09.4 and U09.2 rather than
given a ninth subtopic; the curriculum has no „review“ subtopic, and both are
two-step stories.

## Rules the tests enforce

Spec numbering, and where each is checked in `tests/u09-templates.test.ts`:

1. **Unique IDs** — `covers every subtopic at every level`, plus the catalog's
   own uniqueness test.
2. **Values vary each generation** — capacity probe, see the table below.
3. **No negative results, including intermediate steps** — `never lets a step go
   below zero` walks every printed chain left to right. `g1-u09-1-both-sides`
   computes `a − b + c` and requires the result to differ from all three printed
   numbers.
4. **A two-step expression matches its story exactly** — `matches the expression
   to the story it prints, number for number` and `draws the story arithmetic
   straight`.
5. **True/false computed automatically** — `meets every equality exactly when it
   claims to` recomputes both sides of every claim.
6. **Comparisons evaluate both sides, then read the sign** — `compares by
   evaluating both sides, never by shape`. The sign is *drawn first* and the
   right side built to it; measured `<` 744 / `=` 852 / `>` 804 over 2,400 draws.
   Left to chance, `=` almost never occurs — the U08.8 defect, fixed the same way.
7. **Drag-drop checks final positions** — the drag wording is kept for the
   reason children expect it, but the answer is a click-choice or a number, as
   the engine requires. `g1-u09-8-drag-add` offers four tiles.
8. **Every item has a unique answer** — `builds every puzzle so exactly one
   number closes it` substitutes the answer back in and then asserts that no
   other printed number closes the same sentence.
9. **Template ID, params, answer, grade stored** — the template id is in the
   registry key and the grade in `at()`; the session record holds the rest.

## Two defects the first draft had

Both were caught by probe and by the suite, not by the type checker. The first
is the kind this unit invites; the second is the one U08.8 warned about.

- **`20-mde` levels 1 and 2 were the same questions.** Level 1 drew `a + b` with
  both addends 5–9, level 2 drew the same shape with `a` 5–9 and `b` 6–9 — 98% of
  level 2's questions were already in level 1, so the difficulty ladder did
  nothing. A probe that measured the *overlap between levels*, not just the
  count per level, is what found it: both levels looked healthy in isolation.
  Level 2 is now a teen plus a digit and a teen minus a teen, which cannot be
  counted back one by one, and the overlap is 0.

- **A negative number in an explanation, while the answer stayed correct.**
  `20-mde` level 2 explains itself by bridging to twenty — „14 + 6 = 20, then
  20 − 1 = 19“ — with the step written as `b − (20 − a)`. When `b` was smaller
  than the gap to twenty the arithmetic still came out right, so every test on
  the *answer* passed, but the printed explanation read „20 − -1 = 19“. Rule 3
  is about intermediate values, and an explanation is one. The step is now
  worded as a decomposition that holds for every draw (`14 = 10 + 4, therefore
  10 + 4 + 5 = 19`), rather than constraining the draw pool to fit the prose.

Both were invisible in the type checker and in any test that only checks the
answer; a probe that reads the printed text is what catches them.
