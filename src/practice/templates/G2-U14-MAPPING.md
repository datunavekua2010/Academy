# Grade 2 Unit 14: კანონზომიერებები და ლოგიკა (Patterns & Logic)

## Overview
Unit 14 (`g2-kanonzomiereba-logika`) introduces Grade 2 students to identifying, continuing, and formulating repeating and growing patterns with colors, shapes, and numbers; deducing arithmetic rules (adding, subtracting, doubling); solving additive number triangles; cracking numeric and symbolic code puzzles; guessing numbers based on intervals and digit constraints; solving age word problems across present, past, and future; applying elimination techniques to find the odd one out; selecting items according to single and multiple color and shape criteria; reasoning about balance scales and comparative weights; and matching complex conditions to find unique solutions.

## Architecture & Subtopics
The unit contains **78 dynamic question templates** (Q01–Q78) evenly distributed across **13 subtopics** (6 questions each) covering progressive difficulty levels (Level 1, Level 2, Level 3):

1. **U14.1: განმეორებადი კანონზომიერებები** (`u14-repeating-patterns`, Q01–Q06)
   - Q01 (Level 1, MC): ფერების მარტივი მიმდევრობის გაგრძელება (AB ABA -> B).
   - Q02 (Level 1, MC): ფორმების განმეორებადი მიმდევრობა (AAB AAB AAB -> B).
   - Q03 (Level 2, MC): რიცხვების მონაცვლეობის გაგრძელება (A, B, A, B, A, __).
   - Q04 (Level 2, MC): ორმაგი ფერის/ფორმის მიმდევრობა (AAB AAB -> A).
   - Q05 (Level 3, MC): გამოტოვებული ფორმის პოვნა მიმდევრობის შუაში (A B A B [A] B).
   - Q06 (Level 3, MC): რიცხვების პერიოდული მიმდევრობა (A, B, A, B, A, B, __ -> A).

2. **U14.2: მზარდი კანონზომიერებები** (`u14-growing-patterns`, Q07–Q12)
   - Q07 (Level 1, MC): შემდეგი რიცხვი (+3 ნაბიჯით).
   - Q08 (Level 1, MC): შემდეგი რიცხვი (+5 ნაბიჯით).
   - Q09 (Level 2, MC): შემდეგი რიცხვი (+2 ნაბიჯით კენტ/ლუწ რიცხვებში).
   - Q10 (Level 2, MC): შემდეგი რიცხვი (+3 ნაბიჯით დაწყებული 2-დან).
   - Q11 (Level 3, MC): შემდეგი ათეული (+10 ნაბიჯით).
   - Q12 (Level 3, MC): შემდეგი რიცხვი (+3 ნაბიჯით დაწყებული 1-დან).

3. **U14.3: კანონზომიერების წესის ამოცნობა** (`u14-describing-the-rule`, Q13–Q18)
   - Q13 (Level 1, MC): მიმდევრობის ზრდის წესის განსაზღვრა (+4).
   - Q14 (Level 1, MC): კლებადი მიმდევრობის წესის განსაზღვრა (−2).
   - Q15 (Level 2, MC): იმ მიმდევრობის არჩევა, რომელიც ყოველ ჯერზე იზრდება 5-ით.
   - Q16 (Level 2, MC): წესის შესაბამისობა მოცემულ მიმდევრობასთან (+6).
   - Q17 (Level 3, MC): კლებადი მიმდევრობის წესის პოვნა (−5).
   - Q18 (Level 3, MC): გაორმაგების წესის (×2) ამოცნობა მიმდევრობებში.

4. **U14.4: რიცხვების სამკუთხედები** (`u14-number-triangles`, Q19–Q24)
   - Q19 (Level 1, Numeric): გამოტოვებული ქვედა რიცხვის პოვნა (top − b1).
   - Q20 (Level 1, Numeric): სამკუთხედის შევსება — მეორე ქვედა რიცხვი (top − b1).
   - Q21 (Level 2, Numeric): ზედა რიცხვის გამოთვლა (b1 + b2).
   - Q22 (Level 2, Numeric): გამოტოვებული ქვედა რიცხვის გამოთვლა (top − b1).
   - Q23 (Level 3, Numeric): სამკუთხედის ზედა რიცხვი ორნიშნა ჯამით (b1 + b2).

5. **U14.5: რიცხვის გამოცნობა** (`u14-number-guessing`, Q25–Q30)
   - Q25 (Level 1, MC): ლუწი რიცხვის გამოცნობა მოცემულ შუალედში.
   - Q26 (Level 1, MC): რიცხვის გამოცნობა ათეულებს შორის ერთეულების ციფრით 5.
   - Q27 (Level 2, Numeric): რიცხვის გამოცნობა შეკრების პირობით (x + a = sum -> x = sum − a).
   - Q28 (Level 2, MC): რიცხვის გამოცნობა ათეულებს შორის ერთეულების ციფრით 2.
   - Q29 (Level 3, Numeric): რიცხვის გამოცნობა გამოკლების პირობით (x − sub = diff -> x = diff + sub).
   - Q30 (Level 3, MC): 5-ის ჯერადი / 5-ით დაბოლოებული რიცხვის პოვნა შუალედში.

6. **U14.6: სიტყვების კოდირება** (`u14-word-coding`, Q31–Q36)

   - Q36 (Level 3, Numeric): სამი გეომეტრიული ფიგურის კოდი (▲ + ■ + ■).

8. **U14.8: გამორიცხვის მეთოდი** (`u14-elimination`, Q43–Q48)
   - Q43 (Level 1, MC): განსხვავებული რიცხვის გამორიცხვა (მაგ. ლუწებში კენტი).

   - Q47 (Level 3, MC): კანონზომიერების დამრღვევი რიცხვის პოვნა მიმდევრობაში.
   - Q48 (Level 3, MC): განსხვავებული საზომი ერთეულის გამორიცხვა (დროის ერთეულები vs მასა/სიგრძე).

   - Q51 (Level 2, MC): ორი პირობის შეხამება (მაგ. ყვითელი ვარსკვლავი).
   - Q52 (Level 2, MC): ფერის კოდის ამოხსნა (რომელი ფერი აღნიშნავს მოცემულ რიცხვს).
   - Q53 (Level 3, MC): მოცემული ფერის ფორმის არჩევა.

10. **U14.10: სასწორები და წონის ლოგიკა** (`u14-balance-scales`, Q55–Q60)
    - Q55 (Level 1, MC): წონების შედარება — რომელი საგანია უფრო მძიმე.
    - Q56 (Level 1, Numeric): სასწორის ამოცანა — N ცალი ერთნაირი საგნის წონა.
    - Q57 (Level 2, Numeric): რამდენი ერთეულით მძიმეა მეორე საგანი (w2 − w1).
    - Q58 (Level 2, Numeric): თანაბარი წონა — რამდენი საგანი იწონის ჯამურ წონას (total : w).

    - Q60 (Level 3, Numeric): ორი ერთნაირი საგნის საერთო წონა (w × 2).

    - Q62 (Level 1, MC): ერთადერთი რიცხვის პოვნა შუალედითა და ერთეულების ციფრით.
    - Q63 (Level 2, MC): სამი პირობის დაკმაყოფილება (ქვედა ზღვარი, ზედა ზღვარი, ლუწობა).

    - Q66 (Level 3, MC): ყველაზე მძიმე საგნის პოვნა ოთხი მოცემულიდან.

12. **U14.12: ჩაფიქრებული რიცხვი** (`u14-thought-of-number`, Q67–Q72)
    - Q67 (Level 1, Numeric): x + add = sum -> x = sum − add.
    - Q68 (Level 1, Numeric): x − sub = diff -> x = diff + sub.
    - Q69 (Level 2, Numeric): x × 2 = doubled -> x = doubled : 2.
    - Q70 (Level 2, Numeric): x + 10 = sum -> x = sum − 10.
    - Q71 (Level 3, Numeric): x − sub = diff (ორნიშნა რიცხვებით).
    - Q72 (Level 3, Numeric): x + add = sum (20-მდე გადასვლით).

13. **U14.13: პირობების შეხამება** (`u14-matching-conditions`, Q73–Q78)

    - Q74 (Level 1, MC): ორი პირობა: ლუწი რიცხვი მოცემულ შუალედში.
    - Q75 (Level 2, MC): ჯერადი და ზღვარზე ნაკლები (k-ის ჯერადი < limit).
    - Q76 (Level 2, MC): სამი პირობა: ათეულების შუალედი და ერთეულების ციფრი.

    - Q78 (Level 3, MC): სამი ყუთის ლოგიკური ამოცანა (დალაგებული რაოდენობები -> მეორე ყუთი).
